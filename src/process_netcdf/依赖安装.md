既然你已经卸载了 Miniconda，我们就不再使用之前的 `nco_env` 环境路径了。现在，我们将使用你**系统自带的 Python**（从你之前的 PATH 环境变量中，我看到你安装了 `Python314`）来从头配置一个干净的环境。

以下是为你量身定制的**全新安装指南**：

### 第一步：确认系统 Python 可用
打开 PowerShell，输入以下命令确认你的 Python 路径和版本：
```powershell
py --version
```
> *如果提示找不到命令，请尝试使用 `py --version` 或 `C:\Users\89695\AppData\Local\Programs\Python\Python314\python.exe --version`*

### 第二步：升级 pip（防止版本过旧）
```powershell
py -m pip install --upgrade pip --trusted-host pypi.tuna.tsinghua.edu.cn -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 第三步：一键安装所有核心依赖
这条命令会安装 `netCDF4`、`xarray`、`numpy` 以及处理大文件可选的 `dask`：
```powershell
python -m pip install netCDF4 xarray numpy dask --trusted-host pypi.tuna.tsinghua.edu.cn -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 第四步：验证安装结果
运行以下命令，确认所有包都能正常导入且版本合理：
```powershell
py -c "import netCDF4; import xarray; import numpy; print(f'netCDF4: {netCDF4.__version__}'); print(f'xarray:  {xarray.__version__}'); print(f'numpy:   {numpy.__version__}')"
```
✅ **预期输出示例**（版本号可能略有不同）：
```text
netCDF4: 1.7.x
xarray:  202x.x.x
numpy:   2.x.x
```

### 第五步：运行脚本测试
将之前提供的 `process_netcdf.py` 保存到任意目录（例如 `D:\scripts\process_netcdf.py`），然后执行：
```powershell
py D:\scripts\process_netcdf.py "D:\path\to\your\file.nc"
```
确认同目录下成功生成了 `scaled.nc` 和 `uv.nc`，即表示你的新环境已经完全就绪！
